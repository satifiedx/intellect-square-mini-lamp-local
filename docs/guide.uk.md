# Керуємо лампою INTELLECT з Telegram: проста інструкція

[English](guide.md)

Програмувати не треба. Якщо вмієш встановити програму і скопіювати кілька рядків, у тебе вийде. Перший раз займе приблизно годину.

## Що ти отримаєш

Твоя лампа INTELLECT Square Mini Lamp слухатиметься Telegram бота замість офіційного додатка. Будуть кнопки для кольорів, яскравості, усіх 19 ефектів, таймерів, будильника-світанку і збережених сцен. Ще можна надіслати голосове на кшталт "зроби тепліше і тьмяніше", і лампа це зробить. Усе лишається у твоїй домашній мережі, нічого не йде через сервер виробника.

## Як це працює простими словами

У лампи є одна звичка: при старті вона шукає адресу `intellect.properties` і підключається до того, що там знайде. Зазвичай це сервер виробника. Ми змінюємо "телефонну книгу" твоєї домашньої мережі так, щоб це ім'я вказувало на твій власний маленький комп'ютер. На ньому працює програма (бот), яка вдає з себе сервер виробника і ще й розмовляє з Telegram. Тож лампа думає, що говорить із виробником, а насправді говорить із тобою.

Побічний ефект: поки це ввімкнено, офіційний додаток INTELLECT лампу не бачить. Повернути все назад можна будь-коли.

## Що потрібно

- лампа, яка вже працює з твоїм Wi-Fi (2.4 ГГц)
- комп'ютер, який увімкнений, коли ти хочеш користуватися лампою: старий ПК чи ноутбук, Raspberry Pi, міні сервер. Комп'ютер, який ти вимикаєш на ніч, теж підійде, але тоді лампа слухається бота лише поки він увімкнений
- Python 3.10 або новіший на цьому комп'ютері
- акаунт Telegram
- доступ до налаштувань роутера, де можна змінити один запис DNS (крок 5, там є варіанти для більшості роутерів)
- за бажанням: безкоштовний акаунт на console.groq.com для голосових і текстових команд

## Крок 1. Створи свого бота в Telegram

1. Відкрий Telegram, знайди **@BotFather**, почни чат.
2. Надішли `/newbot`, дай відповідь на два запитання (назва і юзернейм, що закінчується на `bot`).
3. BotFather надішле довгий токен на кшталт `123456:ABC...`. Скопіюй його. Це ключ до твого бота, нікому його не показуй.

## Крок 2. За бажанням: ключ Groq для голосу

1. Зайди на console.groq.com, зареєструйся.
2. Створи API ключ і скопіюй його.

Цей крок пропусти, якщо тобі потрібні тільки кнопки.

## Крок 3. Постав бота на комп'ютер

1. Завантаж проєкт: на сторінці GitHub натисни зелену кнопку **Code**, потім **Download ZIP**, розпакуй. Якщо знаєш git: `git clone` репозиторію.
2. Відкрий термінал у цій папці (у Windows: відкрий папку, клацни в адресний рядок, напиши `cmd`, натисни Enter).
3. Встанови потрібне:
   ```
   pip install -r requirements.txt
   ```
4. Створи файл налаштувань: скопіюй `.env.example` у новий файл з назвою `.env` (саме така назва). Відкрий у Блокноті і заповни:
   ```
   BOT_TOKEN=токен від BotFather
   ALLOWED_IDS=
   GROQ_API_KEY=твій ключ Groq, або залиш порожнім
   ```
5. Запусти бота:
   ```
   python lampbot.py
   ```
   У Windows з'явиться вікно брандмауера. Дозволь доступ для **приватних мереж**. Вікно терміналу залиш відкритим.

## Крок 4. Скажи боту, що це ти

1. У Telegram відкрий свого нового бота і натисни **Start**.
2. Він відповість "Access denied" і покаже **твій Telegram id**, це число.
3. Впиши це число в `.env`: `ALLOWED_IDS=123456789` (кілька людей: через кому).
4. Зупини бота (Ctrl+C у терміналі) і запусти знову.
5. Надішли боту `/menu`. З'явиться панель із кнопками. Лампа поки не реагує, це нормально.

Відтепер лампою можуть керувати тільки люди зі списку `ALLOWED_IDS`.

## Крок 5. Направ лампу на свій комп'ютер

Спершу дай комп'ютеру постійну адресу, інакше наступні кроки зламаються, коли вона зміниться. У роутері знайди "DHCP reservation", "static lease" чи "резервація адреси" і прив'яжи комп'ютер до його поточного IP. Запиши цей IP, нижче він називається `YOUR_PC_IP`.

Потім зроби так, щоб ім'я `intellect.properties` вказувало на `YOUR_PC_IP`. Вибери рядок для свого роутера:

- **OpenWrt:** у терміналі на роутері
  ```
  uci add_list dhcp.@dnsmasq[0].address='/intellect.properties/YOUR_PC_IP'
  uci commit dhcp
  /etc/init.d/dnsmasq restart
  ```
- **Pi-hole:** Local DNS, DNS Records, додай `intellect.properties` з `YOUR_PC_IP`.
- **AdGuard Home:** Filters, DNS rewrites, додай `intellect.properties` з `YOUR_PC_IP`.
- **MikroTik:** `/ip dns static add name=intellect.properties address=YOUR_PC_IP`
- **Роутери на dnsmasq (DD-WRT, Asus Merlin, Tomato):** додай `address=/intellect.properties/YOUR_PC_IP` у власні опції dnsmasq.
- **pfSense / OPNsense:** DNS Resolver (Unbound), host override.
- **Роутери Grandstream GWN:** Network Settings, LAN, вкладка Local DNS Records, додай запис. Потім на тій самій сторінці LAN відкрий свою мережу і постав у DHCP "Preferred DNS Server" адресу самого роутера, інакше пристрої користуються публічним DNS і ігнорують запис.
- **У твого роутера нічого такого немає (більшість домашніх):** скористайся вбудованим DNS бота. У `.env` додай `DNS_STUB=1`, перезапусти бота, потім у налаштуваннях DHCP роутера вкажи DNS сервером `YOUR_PC_IP` (а запасним DNS адресу самого роутера). Подробиці в головному README.

## Крок 6. Перевір і перепідключи лампу

1. На будь-якому комп'ютері в мережі виконай `nslookup intellect.properties`. У відповіді має бути `YOUR_PC_IP`. Якщо там щось інше, зачекай хвилину-дві (DNS якийсь час тримає старі відповіді) і спробуй знову.
2. Висмикни лампу на 3 секунди, встав назад.
3. Приблизно за 30 секунд у вікні бота з'явиться `lamp found`.
4. Відкрий бота, надішли `/menu`, натисни кнопку. Лампа реагує.

## Крок 7. Щоб бот запускався сам

Щоб не запускати бота вручну після кожного перезавантаження.

**Windows:** відкрий термінал і виконай (шлях заміни на свою папку, лапки лиши):
```
schtasks /create /tn "lampbot" /sc onlogon /tr "pythonw C:\path\to\the\folder\lampbot.py"
```
Тепер бот стартує, коли ти входиш у систему, без вікна.

**Linux або Raspberry Pi** (права адміна не потрібні): створи у папці проєкту файл `run.sh`
```
#!/bin/sh
cd "$HOME/lampbot" || exit 1
exec flock -n .lock python3 -u lampbot.py >> bot.log 2>&1
```
зроби його виконуваним (`chmod +x run.sh`) і додай у cron раз на хвилину (`crontab -e`, потім рядок `* * * * * $HOME/lampbot/run.sh`). Якщо бот уже працює, зайвий запуск нічого не робить, а якщо він упав або машину перезавантажили, він стартує знову.

## Як користуватися

- `/menu` це панель кнопок, одне повідомлення, яке саме оновлюється.
- Голосом або текстом, без жодних команд: "увімкни метеор, синій з фіолетовим", "зроби тепліше і тьмяніше", "таймер сну на 20 хвилин", "розбуди мене о 7:30", "увімкни сцену вечір".
- `/save вечір` зберігає, як лампа виглядає зараз, а `/scenes` повертає це.
- Усі команди в головному README.

## За бажанням: щоб офіційний додаток теж працював

За замовчуванням офіційний додаток INTELLECT перестає бачити лампу, бо вона тепер розмовляє з твоїм ботом. Якщо додаток усе ж потрібен, додай `CLOUD_BRIDGE=1` у `.env`, перезапусти бота і один раз перезапусти живлення лампи. Тоді бот передає команди з додатка лампі, а стан лампи додатку. У меню бота в `More` є перемикач, що дозволяє або блокує додаток. Для цього потрібен інтернет на комп'ютері з ботом, а ще стан твоєї лампи знову йде виробнику, тому за замовчуванням це вимкнено.

## Кольори і пресети

Крім кнопок кольорів, можна надіслати боту будь-який колір повідомленням: `#ff8800`, `255 100 0` або назву на кшталт `teal`. На сторінці `Scenes` є готові пресети (reading, relax, movie, night, focus, party, fireplace, ocean, sunset, meteor).

## Щось не так

- **Бот не відповідає в Telegram:** термінал має бути ще відкритий і без помилок. Перевір, що в `.env` навколо токена немає пробілів.
- **"Access denied":** твого id немає в `ALLOWED_IDS`, або ти не перезапустив бота після правки.
- **Лампа так і не показує `lamp found`:** лампа і комп'ютер мають бути в одній мережі (без гостьового Wi-Fi). Брандмауер має пропускати вхідні TCP на порт 1883. Запис DNS має вказувати на актуальний IP комп'ютера. VPN на комп'ютері теж може ховати його від лампи.
- **Команди нічого не роблять, а лампа знайдена:** зачекай 30 секунд після увімкнення лампи, вона спершу має повідомити свій стан.
- **Бот працює, а офіційний додаток загубив лампу:** так і має бути, дивись нижче.

## Повернутися до офіційного додатка

Прибери запис DNS із роутера (або вимкни DNS заглушку), висмикни лампу на кілька секунд, встав назад. Офіційний додаток знову працює.

## Безпека

- Ніколи не відкривай порт 1883 цього комп'ютера в інтернет. Тоді будь-хто зможе керувати твоєю лампою.
- Тримай `.env` приватним, там токен твого бота. Нікуди його не завантажуй.
- Зміни стандартний пароль свого роутера.
