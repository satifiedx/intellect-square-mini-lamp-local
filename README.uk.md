# INTELLECT Square Mini Lamp, локальне керування

[English version](README.md)

Керуємо лампою INTELLECT Square Mini Lamp без хмари виробника. Невеликий скрипт вдає з себе сервер виробника, лампа підключається до нього, а ти керуєш нею з Telegram бота: кнопками, текстом або голосовими.

Неофіційний проєкт, до INTELLECT стосунку не має. Все на свій ризик.

## Як це працює

У лампі ESP8266 (модуль ESP-07S) із закритою прошивкою. Порти в локальній мережі всі закриті, але при старті лампа дуже балакуча. Я поснифив її на роутері через tcpdump і з'ясував:

1. Вона резолвить `intellect.properties` через звичайний DNS.
2. По голому HTTP на порт 80 питає `GET /firmwares/v1/products/<id>/firmware-version` і чекає `{"firmware_version":"6"}`.
3. Підключається до цього хоста на порт 1883 звичайним MQTT, без TLS. Логін і пароль шле, але твій власний брокер приймає будь-які.
4. Усі топіки за конвенцією Homie: `<64 hex префікс>/sweet-home/<mac>/led-module/led-on` і так далі. Щоб керувати, пиши в той самий топік із `/set` в кінці.

Тож фокус простий: змусити `intellect.properties` вказувати на твою машину, підняти там MQTT брокер і спілкуватися з лампою через публікації в її `/set` топіки. `lampbot.py` робить усе це одним процесом:

- вбудований MQTT брокер (amqtt) на порту 1883
- крихітна HTTP заглушка на порту 80, яка відповідає на перевірку версії прошивки
- MQTT клієнт, який сам знаходить префікс і mac лампи
- Telegram бот (aiogram) зі списком дозволених id
- опційно голос і вільний текст через Groq (Whisper для мови, LLM щоб перетворити фразу на команди лампі)

Повний список топіків і діапазони значень: [docs/protocol.md](docs/protocol.md).

## Що потрібно

- Python 3.10+
- машина в локальній мережі, яка увімкнена, коли хочеш користуватися лампою (ПК, Raspberry Pi, міні сервер)
- роутер або DNS сервер, де можна перевизначити одне ім'я хоста (OpenWrt, Pi-hole, AdGuard Home, звичайний dnsmasq, більшість кастомних прошивок)
- токен Telegram бота від @BotFather
- опційно безкоштовний ключ Groq з console.groq.com для голосу і текстових команд

## Встановлення

```
git clone https://github.com/satifiedx/intellect-square-mini-lamp-local
cd intellect-square-mini-lamp-local
pip install -r requirements.txt
cp .env.example .env
```

Заповни `.env`:

```
BOT_TOKEN=123456:твій-токен
ALLOWED_IDS=
GROQ_API_KEY=
```

Запуск:

```
python lampbot.py
```

Порт 80 на Linux і macOS потребує прав адміна (`sudo`), або постав `HTTP_PORT=8080` у `.env`, але тоді лампа до заглушки не достукається. Заглушка необов'язкова, без неї лампа просто трохи довше вантажиться.

На Windows дозволь Python у брандмауері для приватних мереж, інакше лампа не дістанеться до портів 1883 і 80.

Тепер напиши боту `/start`. Він відповість твоїм Telegram id, впиши його в `ALLOWED_IDS` (через кому, якщо людей кілька) і перезапусти бота. Поки список порожній, бот нікого не слухає.

## Направити лампу на свою машину

Спочатку дай машині з ботом статичний IP або резервацію в DHCP, потім перевизнач ім'я `intellect.properties` на цей IP.

OpenWrt:

```
uci add_list dhcp.@dnsmasq[0].address='/intellect.properties/192.168.1.50'
uci commit dhcp
/etc/init.d/dnsmasq restart
```

Звичайний dnsmasq:

```
address=/intellect.properties/192.168.1.50
```

Pi-hole: Local DNS, DNS Records, додай `intellect.properties` з IP.

AdGuard Home: Filters, DNS rewrites, додай `intellect.properties` з IP.

Інші роутери, що вміють перевизначати одне ім'я:

- прошивки на dnsmasq (DD-WRT, Asus Merlin, Tomato): додай `address=/intellect.properties/192.168.1.50` у власні опції dnsmasq
- MikroTik: `/ip dns static add name=intellect.properties address=192.168.1.50`
- pfSense: Services, DNS Resolver, Host Overrides. OPNsense: Services, Unbound DNS, Overrides

### У роутері такого немає? Нехай це зробить бот

Більшість роутерів не вміють перевизначати одне ім'я, але дозволяють вибрати DNS сервер, який роздає DHCP. Для цього в боті є крихітний вбудований DNS сервер:

1. У `.env` постав `DNS_STUB=1`. За бажанням `DNS_UPSTREAM=192.168.1.1` (куди пересилаються всі інші імена, за замовчуванням `8.8.8.8`, порт можна додати так `1.1.1.1:53`) і `LAN_IP=192.168.1.50`, якщо бот неправильно вгадає адресу машини.
2. Запусти бота. У логу з'явиться `dns stub on port 53`. Порт 53 на Linux і macOS потребує прав адміна, а на Windows він має бути вільний (Docker, WSL або спільний доступ до інтернету можуть його займати).
3. У налаштуваннях DHCP роутера вкажи IP цієї машини як DNS сервер. Якщо є друге поле DNS, впиши туди IP самого роутера або `1.1.1.1` як запасний.
4. Перепідключи лампу (висмикни і встав), щоб вона підхопила новий DNS.

Заглушка відповідає на `intellect.properties` IP цієї машини, а все інше пересилає без змін. Підступ у тому, що всі пристрої в мережі тепер питають імена в цієї машини, тож дай їй фіксований IP і знай, що поки вона вимкнена, пошук імен якийсь час буде повільним (для цього й потрібен запасний DNS).

Перевір з будь-якого ПК: `nslookup intellect.properties` має віддати твою машину. Потім висмикни лампу і встроміть назад. У логу бота з'явиться http запит, а потім `lamp found`.

Щоб відкотити, прибери перевизначення (на OpenWrt `uci del_list dhcp.@dnsmasq[0].address='/intellect.properties/192.168.1.50'`, commit, перезапуск dnsmasq) і перевстав лампу.

## Як користуватися ботом

| Команда | Що робить |
| --- | --- |
| `/menu` | пульт кнопками |
| `/on`, `/off` | живлення |
| `/status` | стан, кольори, режим, швидкість, сигнал wifi, аптайм |
| `/brightness 1-100` | яскравість |
| `/color red`, `/color #ff8800`, `/color 255 100 0` | колір 1 (заодно вмикає лампу) |
| `/color2 ...`, `/color3 ...` | кольори 2 і 3 |
| `/mode Meteor` | ефект за назвою, `/modes` покаже кнопки всіх |
| `/speed 0-100`, `/intensity 0-100` | швидкість і інтенсивність ефекту |
| `/timer 00:30`, `/timer off` | таймер сну, лампа вимикається через цей час |
| `/sunrise 07:30`, `/sunrise on`, `/sunrise off` | будильник світанку |
| `/fade 00:05` | тривалість згасання |
| `/micsens 0-100`, `/micnoise 0-100` | чутливість мікрофона і шум для звукових режимів |
| `/eco on`, `/eco off` | режим економії (нижчий ліміт струму) |
| `/save вечір`, `/scenes`, `/scene вечір` | зберегти поточний вигляд (режим, кольори, яскравість, швидкість, інтенсивність) під іменем і повернути його пізніше |

Назви кольорів працюють англійською, російською й українською.

### Голос і вільний текст

Якщо заданий `GROQ_API_KEY`, просто шли голосове або звичайний текст, команда не потрібна:

- "вмикай метеор, синій з фіолетовим, на повну швидкість"
- "зроби тепліше і тьмяніше"
- "turn on rainbow, slower"
- "постав таймер сну на 20 хвилин"
- "розбуди мене о пів на восьму"
- "увімкни сцену вечір"

Голос іде в Groq Whisper, текст іде в LLM з коротким промптом, що повертає JSON зі списком дій, бот їх виконує і відповідає, що зробив. За замовчуванням LLM це `openai/gpt-oss-20b` на Groq, змінюється через `GROQ_LLM` у `.env`, якщо Groq перейменує або прибере модель (`GET https://api.groq.com/openai/v1/models` покаже, що в тебе є).

Якщо встановлений Antigravity CLI (`agy`), його можна використовувати як мізки: постав `AGENT=agy` і за бажанням `AGY_MODEL` та `AGY_EXE`. Це повільніше (від 5 до 20 секунд на фразу), а якщо впаде або буде думати довше 45 секунд, бот перейде на Groq.

## Режими

Лампа сама віддає повний список:

Solid, Solid 2, Solid 3, Percent, Percent 2, Strobe, Rainbow, Gradient, Fireworks, Meteor, Fire, Blends, Random colors, Plasma, Sound reactive percent, Sound reactive lighthouse, Sound reactive fire, Sound reactive equalizer, Sound reactive strobe.

Що видно з трафіку офіційного додатка: Solid режими беруть колір 1, Gradient і Plasma ще й колір 2, Meteor бере два кольори, Strobe залежить від швидкості, звукові режими використовують `led-mic-sens` і `led-mic-noise`. Кожен режим я не перевіряв, тож якщо дізнаєшся більше, кидай issue або PR.

## Залізо і прошивка

Усе, що я знайшов про лампу, лежить у `docs`:

- [docs/hardware.uk.md](docs/hardware.uk.md): що є на платі, контакти ESP-07S, підключення UART
- [docs/firmware.uk.md](docs/firmware.uk.md): родна прошивка (ESP8266 RTOS SDK), розмітка флешу, час завантаження, сервіси
- [docs/protocol.uk.md](docs/protocol.uk.md): усі MQTT топіки і діапазони значень
- [docs/flashing.uk.md](docs/flashing.uk.md): моя спроба прошити по UART, що не вийшло, що пробувати, як отримати WLED іншим шляхом
- [docs/boot-log.txt](docs/boot-log.txt) і [docs/homie-description.txt](docs/homie-description.txt): сирий матеріал, з якого прибрано пароль Wi-Fi, дані MQTT, mac, IP і країну

Коротко: ESP8266 із флешем 4 МБ і двома слотами OTA, дані стрічки на GPIO3 через I2S, UART на 74880 бод. Лампа входить у режим завантаження по UART, але змусити чип відповідати `esptool` мені не вдалося, тож дампу прошивки ще немає. Допомога вітається, дивись [docs/flashing.uk.md](docs/flashing.uk.md).

## Варто знати

- Поки DNS перевизначення увімкнене, офіційний додаток не бачить лампу в домашньому Wi-Fi, бо додаток говорить з хмарою, а лампа говорить з тобою. Прибери перевизначення, щоб повернутися.
- Машина з ботом має бути увімкнена, інакше в лампи немає брокера.
- Брокер слухає `0.0.0.0:1883` і приймає будь-що. Тримай його в локальній мережі, ніколи не прокидай цей порт в інтернет.
- Telegram бот слухається тільки id з `ALLOWED_IDS`.
- Поради по Wi-Fi, якщо лампа глючить: чип тільки 2.4 ГГц, став фіксований канал (1, 6 або 11), ширину 20 МГц, WPA2-PSK, і вимкни 802.11w та 802.11r для цієї мережі.
- Перевірено на прошивці `20230815_2.0.0`.
